# repo-prueba
Repositorio para prueba técnica

## Angular

**Requisitos:**
- Node.js 18+
- npm

**Comandos:**
```bash
cd angular-patitas
npm install
ng serve
```

## Spring

**Requisitos:**
- Java 17+
- Maven

**Comandos:**
```bash
cd spring-patitas
./mvnw.cmd spring-boot:run
```

## 🚀 El servidor iniciará en:
- **URL**: http://localhost:8080
- **Swagger UI**: http://localhost:8080/swagger-ui.html
- **H2 Console**: http://localhost:8080/h2-console
